# Family Build

第一代 AI 原生家庭社区。陪孩子一起 Learn · Think · Build · Grow。

这是 Family Build 的介绍网页源码，纯静态 HTML，无需构建。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 目录结构

```
index.html   页面（含样式与脚本）
*.jpg / *.webp  Logo 与海报图片
```

## 在线访问

通过 GitHub Pages 部署：Settings → Pages → Branch 选 `main` / `(root)`。
